# AI 服务测试分层

所有命令从 `governance-suite` 根目录执行。按[单实例规范](AGENTS.md#部署范围单实例)验收，先选择能证明本次改动的最小范围；各层通过只能证明各层覆盖的行为。

## 定向测试与模块测试

核心逻辑、同步／流式契约、路由、幂等与异常路径优先使用外部依赖替身。例如：

```bash
mvn -f ai/ai-chat-service/pom.xml -Dtest=PatientChatRoutingEvaluationTest test
mvn -f ai/ai-chat-service/pom.xml test
node --test ai/ai-chat-service/src/test/js/chat-console.test.cjs
```

共享模块变更再扩大到实际消费者；本机未安装最新共享依赖时，使用根 reactor 的 `-pl <受影响模块> -am` 构建。测试配置、测试名称与实际 Surefire 报告一起记录，不把零测试或跳过算作通过。

## 固定业务回归

固定回归统一运行器、分组、已知缺口和退出码维护在[固定回归说明](evaluation-service/regression/README.md)。可先只查看清单：

```bash
python3 ai/evaluation-service/run_regression.py --list
```

回归默认离线，覆盖路由、请求可靠性、Agent 安全降级和审批已有范围。范围门禁与已执行测试是否通过分别判断，不能通过隐藏缺口将门禁变绿。

## 外部服务集成测试

多数外部集成测试使用 `@EnabledIfSystemProperty(named = "ai.external.tests", matches = "true")` 和 `external-test` profile；按目标模块定向启用，例如：

```bash
mvn -f ai/ai-chat-service/pom.xml -Dtest=AiChatFlowIntegrationTest -Dai.external.tests=true test
```

测试环境需先配置独立的 `AI_TEST_*` 参数，具体见目标模块 `src/test/resources/application-external-test.yml` 与测试类。缺少配置应报告未满足条件，不使用开发数据凑齐验证。

并非所有外部测试都受同一个开关控制：`RpcReplyBrokerIntegrationTest` 由 `AI_TEST_RABBITMQ_HOST` 启用，医生随访集成测试默认使用 H2，可显式指定独立 MySQL。各测试的入口、数据写入与清理行为需先读测试代码。已有双实例 Broker 测试仅用于队列隔离兼容性回归，不构成多实例建设目标。

## 患者对话路由样本

[PatientChatRoutingEvaluationTest](ai-chat-service/src/test/java/com/lx/governance/aichat/evaluation/PatientChatRoutingEvaluationTest.java) 当前读取 [patient-chat-v2.json](ai-chat-service/src/test/resources/evaluation/patient-chat-v2.json)，v1 保留作历史基线。

样本包含患者原文、上下文、期望路由与安全原因，以及将来回答质量评估用的语义信号。当前动态测试只断言路由与安全编排；不能据此声称模型回答、证据覆盖和医学质量已经通过。

## 独立评测与真实调用采集

| 验证内容 | 维护入口 | 可以证明什么 |
| --- | --- | --- |
| 样本版本、确定性规则、报告、持久化与对比 | [评测系统](evaluation-service/README.md) | 导入观测符合给定规则 |
| 实际聊天执行与异步采集 | [真实调用采集](真实调用采集说明.md) | 观测来自指定测试请求链路，仍需辨别缓存、Mock 与模型调用 |
| 医生批准／拒绝与患者收件箱 | [随访演示](高风险随访演示.md)、[医生助手验证](doctor-assistant-agent/README.md#验证) | 对应环境中的登记、审批和投递闭环 |

固定离线回归和真实回答评测是不同产物。语义质量、医学正确性和完整环境联调需独立证据；普通关键词规则或工具摘要不能替代专业审核和真实执行回执。

## 验证报告要求

记录命令、目标模块、样本版本、环境前置条件、执行／失败／跳过数量以及已知缺口。性能改动使用相同样本和数据比较延迟、吞吐、Token 和效果；无实际测量时只报告设计判断。
