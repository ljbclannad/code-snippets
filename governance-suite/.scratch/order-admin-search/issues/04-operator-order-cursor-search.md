# 04 — 运营管理员订单游标检索

**What to build:** `ORDER_OPERATOR` 可通过订单号、脱敏客户标识、商品 ID、订单状态、支付状态、时间和金额范围检索订单，并使用创建时间排序的稳定游标继续翻页。

**Blocked by:** 01 — 后台管理员角色与可信搜索范围；02 — 订单后台读模型的订单投影；03 — 订单后台读模型的支付投影。

**Status:** ready-for-agent

- [ ] 运营管理员可在其字段权限内组合使用规定的订单检索条件。
- [ ] 查询时间跨度超过 90 天、非法页大小或非法游标时，系统拒绝请求并给出稳定错误语义。
- [ ] 以创建时间排序连续读取游标结果时无重复、无缺失。
