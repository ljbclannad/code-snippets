# 06 — 库存管理员实时库存快照

**What to build:** `INVENTORY_VIEWER` 查询订单时可按页批量获取当前库存快照，且库存失败不会阻断订单检索。

**Blocked by:** 01 — 后台管理员角色与可信搜索范围；04 — 运营管理员订单游标检索；05 — 角色字段裁剪与排序白名单。

**Status:** ready-for-agent

- [ ] 同一页的重复商品只被批量查询一次，单次查询不超过 100 个去重商品。
- [ ] 库存查询成功时返回可用量与观测时间；超时、熔断或部分失败时明确返回 `UNAVAILABLE`，订单列表仍可用。
- [ ] 库存快照不参与订单筛选、排序、总数计算或导出。
