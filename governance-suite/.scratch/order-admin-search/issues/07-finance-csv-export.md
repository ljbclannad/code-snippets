# 07 — 财务管理员异步 CSV 导出

**What to build:** `FINANCE_VIEWER` 可创建冻结搜索范围、条件、字段集和读模型水位的异步 CSV 导出任务，并可通过受保护接口下载结果。

**Blocked by:** 01 — 后台管理员角色与可信搜索范围；04 — 运营管理员订单游标检索；05 — 角色字段裁剪与排序白名单。

**Status:** ready-for-agent

- [ ] 非财务角色不能创建、查询或下载订单导出；下载时重新验证身份与权限。
- [ ] 导出冻结查询条件、字段集、角色快照、搜索范围和读模型水位，并仅包含财务角色可见字段。
- [ ] CSV 正确转义并防止公式注入，文件 24 小时后过期且不可访问。
