# 03 — 订单后台读模型的支付投影

**What to build:** 支付事件能独立更新订单后台读模型中的支付投影，处理支付先到、订单先到、重复投递和乱序到达。

**Blocked by:** 02 — 订单后台读模型的订单投影。

**Status:** completed

- [x] 支付状态、支付单号和支付更新时间能写入订单后台读模型并支持后续筛选。
- [x] 支付先于订单或订单先于支付到达时，读模型均保持正确；支付未知不会被表达为未支付。
- [x] 支付事件不覆盖订单字段，重复或旧支付事件不覆盖新支付投影。

2026-09-17 复验：MySQL 集成测试覆盖支付先到、订单先到、未知支付为 `NULL`、支付字段筛选，以及旧回填和重复支付事件不覆盖在线新版本；本地跨服务端到端测试已验证支付投影收敛。
