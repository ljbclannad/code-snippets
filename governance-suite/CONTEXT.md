# 电商后台检索

本上下文定义基于现有分布式订单、支付与库存模块扩展的电商后台检索语言，避免将订单事实、支付投影与实时库存混为一谈。

## 业务对象

**订单**：客户针对指定商品发起的交易记录，保存订单号、客户、商品、数量、金额、交易状态与创建时间等订单事实。
_Avoid_: 支付单、库存记录

**支付**：针对订单执行的资金处理记录，拥有独立于订单交易状态的支付状态。
_Avoid_: 订单状态、履约状态

**库存快照**：检索时从库存事实源读取的某个商品当前可用库存值，不是订单创建时的历史事实。
_Avoid_: 订单库存、库存历史

**后台管理员**：以运营、财务或库存职责访问后台检索能力的已认证用户。
_Avoid_: 客户、下单用户

**运营管理员**：具有 `ORDER_OPERATOR` 角色、可浏览订单运营字段但只能查看脱敏客户标识的后台管理员。
_Avoid_: 财务管理员、库存管理员

**财务管理员**：具有 `FINANCE_VIEWER` 角色、可查看完整客户标识与支付信息，并可创建订单导出任务的后台管理员。
_Avoid_: 运营管理员、库存管理员

**库存管理员**：具有 `INVENTORY_VIEWER` 角色、可查看当前库存快照但不可查看金额与支付信息的后台管理员。
_Avoid_: 运营管理员、财务管理员

## 检索对象

**订单后台读模型**：面向后台订单列表和筛选的冗余 MySQL 查询模型，汇总订单事实与支付状态投影，并允许支付投影暂时未知。
_Avoid_: 订单事实源、订单详情

**支付投影**：从支付事实源派生并写入订单后台读模型的支付单号、支付状态和支付更新时间。
_Avoid_: 订单交易状态

**搜索范围**：由后台管理员的已验证角色解析出的数据与字段可见规则，调用方不能以请求参数扩张该范围。
_Avoid_: 前端筛选条件、租户参数

**游标分页**：以稳定排序键继续读取下一批订单列表的方式，不承诺任意页码跳转。
_Avoid_: 深分页、无约束页码分页

**导出任务**：固化创建者、搜索范围、查询条件、字段集合与读模型水位的异步数据提取请求。
_Avoid_: 即时下载、永久导出文件

**读模型水位**：标识订单后台读模型已接收并可用于查询的一组订单与支付投影的时间或批次位置。
_Avoid_: 交易事实时间、跨服务强一致快照
