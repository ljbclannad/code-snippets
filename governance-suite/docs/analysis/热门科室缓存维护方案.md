# 热门科室缓存维护方案

## 当前问题

### 缓存数据流向

```
┌─────────────────────────────────────────────────────────────┐
│                     数据流向分析                              │
└─────────────────────────────────────────────────────────────┘

1. Gateway 查询流程：
   HotDeptCacheService.isHotDept(scheduleId)
     ↓
   检查 Caffeine 本地缓存
     ↓ (未命中)
   查询 Redis:
     - appointment:schedule:{scheduleId}  ← 排班信息（含 deptId）
     - appointment:dept:hot:{deptId}      ← 科室热门标识
     ↓
   写入 Caffeine 本地缓存（60秒过期）

2. 当前问题：
   ❌ 没有服务负责写入 Redis 中的这两个 key
   ❌ appointment-service 的 StockPreloadService 只预热了库存数据
   ❌ 缺少热门科室标识的维护机制
```

---

## 解决方案

### 方案一：扩展 StockPreloadService（推荐）

在 `appointment-service` 的 `StockPreloadService` 中增加排班信息和热门科室标识的预热。

#### 1. 修改 Department 实体，增加热门标识字段

```java
// appointment-service/entity/Department.java
@TableName("t_department")
public class Department {
    private Long id;
    private String name;
    private Boolean isHot;  // 新增：是否为热门科室
    // ...
}
```

#### 2. 扩展 StockPreloadService

```java
@Service
public class StockPreloadService {
    
    private final ScheduleMapper scheduleMapper;
    private final DepartmentMapper departmentMapper;
    private final StringRedisTemplate redisTemplate;
    private final ObjectMapper objectMapper;

    /**
     * 启动时预热数据
     */
    @PostConstruct
    public void preloadStockOnStartup() {
        String lockKey = "appointment:preload:lock";
        Boolean acquired = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, "1", Duration.ofMinutes(5));

        if (Boolean.FALSE.equals(acquired)) {
            log.info("其他实例正在预热，跳过");
            return;
        }

        try {
            log.info("开始预热数据...");

            // 1. 预热排班库存
            int stockCount = preloadScheduleStock();

            // 2. 预热排班信息（新增）
            int scheduleCount = preloadScheduleInfo();

            // 3. 预热热门科室标识（新增）
            int hotDeptCount = preloadHotDeptFlags();

            log.info("数据预热完成 - 库存: {}, 排班: {}, 热门科室: {}", 
                stockCount, scheduleCount, hotDeptCount);
        } catch (Exception e) {
            log.error("数据预热失败", e);
        } finally {
            redisTemplate.delete(lockKey);
        }
    }

    /**
     * 预热排班信息到 Redis
     * Key: appointment:schedule:{scheduleId}
     * Value: {"id": 123, "deptId": 10, "doctorId": 5, ...}
     */
    private int preloadScheduleInfo() {
        LocalDate startDate = LocalDate.now();
        LocalDate endDate = startDate.plusDays(7);

        LambdaQueryWrapper<Schedule> wrapper = new LambdaQueryWrapper<>();
        wrapper.ge(Schedule::getScheduleDate, startDate)
               .le(Schedule::getScheduleDate, endDate);

        List<Schedule> schedules = scheduleMapper.selectList(wrapper);

        if (schedules.isEmpty()) {
            log.warn("未找到未来 7 天的排班数据");
            return 0;
        }

        for (Schedule schedule : schedules) {
            String key = "appointment:schedule:" + schedule.getId();
            long ttlDays = Math.max(1, ChronoUnit.DAYS.between(startDate, schedule.getScheduleDate()) + 1);

            try {
                // 构造排班信息 JSON
                Map<String, Object> scheduleInfo = new HashMap<>();
                scheduleInfo.put("id", schedule.getId());
                scheduleInfo.put("deptId", schedule.getDeptId());
                scheduleInfo.put("doctorId", schedule.getDoctorId());
                scheduleInfo.put("scheduleDate", schedule.getScheduleDate().toString());
                scheduleInfo.put("totalQuota", schedule.getTotalQuota());
                scheduleInfo.put("remainQuota", schedule.getRemainQuota());

                String json = objectMapper.writeValueAsString(scheduleInfo);

                redisTemplate.opsForValue().set(
                    key,
                    json,
                    Duration.ofDays(ttlDays)
                );
            } catch (Exception e) {
                log.error("预热排班信息失败, scheduleId={}", schedule.getId(), e);
            }
        }

        return schedules.size();
    }

    /**
     * 预热热门科室标识到 Redis
     * Key: appointment:dept:hot:{deptId}
     * Value: "1" (存在即为热门)
     */
    private int preloadHotDeptFlags() {
        // 查询所有热门科室
        LambdaQueryWrapper<Department> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(Department::getIsHot, true);

        List<Department> hotDepts = departmentMapper.selectList(wrapper);

        if (hotDepts.isEmpty()) {
            log.warn("未找到热门科室");
            return 0;
        }

        for (Department dept : hotDepts) {
            String key = "appointment:dept:hot:" + dept.getId();
            
            // 热门标识长期有效（30 天）
            redisTemplate.opsForValue().set(
                key,
                "1",
                Duration.ofDays(30)
            );
        }

        log.info("预热热门科室标识: {}", 
            hotDepts.stream().map(Department::getName).collect(Collectors.joining(", ")));

        return hotDepts.size();
    }

    /**
     * 每小时刷新数据
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void refreshDataHourly() {
        String lockKey = "appointment:refresh:lock";
        Boolean acquired = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, "1", Duration.ofMinutes(5));

        if (Boolean.FALSE.equals(acquired)) {
            log.info("其他实例正在刷新，跳过");
            return;
        }

        try {
            log.info("开始刷新数据...");

            // 1. 刷新库存（只刷新新增的）
            refreshStockIfAbsent();

            // 2. 刷新排班信息（只刷新新增的）
            refreshScheduleInfoIfAbsent();

            // 3. 刷新热门科室标识（全量刷新，因为可能有变化）
            refreshHotDeptFlags();

            log.info("数据刷新完成");
        } catch (Exception e) {
            log.error("数据刷新失败", e);
        } finally {
            redisTemplate.delete(lockKey);
        }
    }

    private void refreshScheduleInfoIfAbsent() {
        // 实现逻辑同 preloadScheduleInfo，但只刷新不存在的 key
    }

    private void refreshHotDeptFlags() {
        // 先删除所有旧的热门标识
        Set<String> oldKeys = redisTemplate.keys("appointment:dept:hot:*");
        if (oldKeys != null && !oldKeys.isEmpty()) {
            redisTemplate.delete(oldKeys);
        }

        // 重新预热
        preloadHotDeptFlags();
    }
}
```

### 方案二：独立的热门科室管理接口

在 `appointment-service` 中创建管理接口，支持手动维护热门科室标识。

```java
@RestController
@RequestMapping("/admin/department")
public class DepartmentAdminController {

    private final DepartmentMapper departmentMapper;
    private final StringRedisTemplate redisTemplate;

    /**
     * 设置科室为热门
     */
    @PostMapping("/{deptId}/hot")
    public ApiResponse<Void> markAsHot(@PathVariable Long deptId) {
        // 1. 更新数据库
        Department dept = departmentMapper.selectById(deptId);
        if (dept == null) {
            return ApiResponse.fail("DEPT_NOT_FOUND", "科室不存在", Trace.getTraceId());
        }

        dept.setIsHot(true);
        departmentMapper.updateById(dept);

        // 2. 写入 Redis
        String key = "appointment:dept:hot:" + deptId;
        redisTemplate.opsForValue().set(key, "1", Duration.ofDays(30));

        // 3. 通知 gateway 刷新缓存（可选：通过 Redis Pub/Sub）
        redisTemplate.convertAndSend("appointment:dept:hot:changed", String.valueOf(deptId));

        log.info("科室已标记为热门, deptId={}, deptName={}", deptId, dept.getName());

        return ApiResponse.ok(null, Trace.getTraceId());
    }

    /**
     * 取消科室热门标识
     */
    @DeleteMapping("/{deptId}/hot")
    public ApiResponse<Void> unmarkAsHot(@PathVariable Long deptId) {
        // 1. 更新数据库
        Department dept = departmentMapper.selectById(deptId);
        if (dept == null) {
            return ApiResponse.fail("DEPT_NOT_FOUND", "科室不存在", Trace.getTraceId());
        }

        dept.setIsHot(false);
        departmentMapper.updateById(dept);

        // 2. 删除 Redis key
        String key = "appointment:dept:hot:" + deptId;
        redisTemplate.delete(key);

        // 3. 通知 gateway 刷新缓存
        redisTemplate.convertAndSend("appointment:dept:hot:changed", String.valueOf(deptId));

        log.info("科室热门标识已取消, deptId={}, deptName={}", deptId, dept.getName());

        return ApiResponse.ok(null, Trace.getTraceId());
    }

    /**
     * 批量同步热门科室标识到 Redis
     */
    @PostMapping("/hot/sync")
    public ApiResponse<Map<String, Object>> syncHotDepts() {
        // 查询所有热门科室
        LambdaQueryWrapper<Department> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(Department::getIsHot, true);
        List<Department> hotDepts = departmentMapper.selectList(wrapper);

        // 先清空旧数据
        Set<String> oldKeys = redisTemplate.keys("appointment:dept:hot:*");
        if (oldKeys != null && !oldKeys.isEmpty()) {
            redisTemplate.delete(oldKeys);
        }

        // 写入新数据
        for (Department dept : hotDepts) {
            String key = "appointment:dept:hot:" + dept.getId();
            redisTemplate.opsForValue().set(key, "1", Duration.ofDays(30));
        }

        Map<String, Object> result = new HashMap<>();
        result.put("syncedCount", hotDepts.size());
        result.put("hotDepts", hotDepts.stream()
            .map(d -> Map.of("id", d.getId(), "name", d.getName()))
            .collect(Collectors.toList()));

        log.info("热门科室标识已同步到 Redis, count={}", hotDepts.size());

        return ApiResponse.ok(result, Trace.getTraceId());
    }
}
```

### 方案三：Gateway 订阅 Redis Pub/Sub（可选）

让 gateway 订阅热门科室变更事件，自动刷新本地缓存。

```java
// gateway 模块
@Configuration
public class RedisPubSubConfig {

    @Bean
    RedisMessageListenerContainer container(
            RedisConnectionFactory connectionFactory,
            HotDeptCacheService hotDeptCacheService) {

        RedisMessageListenerContainer container = new RedisMessageListenerContainer();
        container.setConnectionFactory(connectionFactory);

        // 订阅热门科室变更事件
        container.addMessageListener(
            (message, pattern) -> {
                String deptId = new String(message.getBody());
                log.info("收到热门科室变更事件, deptId={}", deptId);
                
                // 清空相关的本地缓存
                // 注意：需要根据 deptId 找到所有相关的 scheduleId
                hotDeptCacheService.invalidateAll();
            },
            new ChannelTopic("appointment:dept:hot:changed")
        );

        return container;
    }
}
```

## 完整数据流

```
┌─────────────────────────────────────────────────────────────┐
│                   完整数据流（优化后）                         │
└─────────────────────────────────────────────────────────────┘

1. 数据初始化（appointment-service 启动时）：
   StockPreloadService.preloadStockOnStartup()
     ↓
   写入 Redis:
     - appointment:stock:{scheduleId}      ← 库存数据
     - appointment:schedule:{scheduleId}   ← 排班信息（含 deptId）
     - appointment:dept:hot:{deptId}       ← 热门科室标识

2. 定时刷新（每小时）：
   StockPreloadService.refreshDataHourly()
     ↓
   刷新 Redis 数据（新增的排班 + 热门科室变更）

3. 手动维护（管理接口）：
   POST /admin/department/{deptId}/hot
     ↓
   更新数据库 + 写入 Redis + 发布变更事件

4. Gateway 查询（带三级缓存）：
   AppointmentRateLimitFilter
     ↓
   HotDeptCacheService.isHotDept(scheduleId)
     ↓
   L1: Caffeine 本地缓存（60秒）
     ↓ (未命中)
   L2: Redis 缓存（7天）
     ↓ (未命中)
   L3: 降级为普通科室
```

## 总结

**当前问题**：
- ❌ Redis 中缺少 `appointment:schedule:{scheduleId}` 和 `appointment:dept:hot:{deptId}` 数据
- ❌ 没有服务负责维护这些数据

**解决方案**：
- ✅ 扩展 `StockPreloadService`，启动时预热排班信息和热门科室标识
- ✅ 创建管理接口，支持手动维护热门科室
- ✅ 定时刷新机制，保证数据一致性

**优化效果**：
- ✅ Gateway 可以正常查询热门科室信息
- ✅ 三级缓存生效：Caffeine（60s） → Redis（7天） → 降级
- ✅ 支持动态调整热门科室，无需重启服务
