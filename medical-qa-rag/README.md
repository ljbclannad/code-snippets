# 医疗QA RAG

## 简介

医疗QA RAG 是一个基于 RAG 的医疗领域问答系统，旨在通过自然语言处理和机器学习技术，实现医疗领域知识的高效检索和问答。

## 技术栈

- Python
- PyTorch
- Transformers
- LangChain
- RAG

## 项目结构

- crawler：医疗文档爬虫
- knowledge-base：医疗知识库
- model：医疗模型
- server：医疗问答服务
- frontend：医疗问答前端

## 快速开始

1. 安装依赖
2. 运行爬虫
3. 运行知识库清洗
4. 运行知识库向量化
5. 运行知识库构建
6. 运行问答服务
7. 运行问答前端

## 使用方法

1. 访问爬虫管理后台
2. 上传医疗文档
3. 等待文档处理完成
4. 发布文档到知识库
5. 访问问答服务
6. 访问问答前端
7. 开始提问
